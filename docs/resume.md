# Описание проекта для резюме

## Короткая версия

**LLM Quantization & Efficient Inference**

Разработал pipeline посттренировочного квантования Qwen2.5-0.5B в INT8 и INT4 на Apple Silicon с использованием MLX. Для INT4 ускорил декодирование в 1,65× и снизил пиковую выделенную память на 62% относительно FP16. Для INT8 получил ускорение 1,43× при сохранении 99,81% next-token accuracy на WikiText-2

## Версия для блока с буллетами

- Реализовал воспроизводимый pipeline конвертации и группового affine-квантования Qwen2.5-0.5B в INT8/INT4 через MLX
- Ускорил INT4-декодирование в 1,65× и снизил пиковую память MLX на 62,1% относительно FP16
- Сохранил 99,81% next-token top-1 accuracy в INT8 при ускорении 1,43× и росте perplexity всего на 0,09%
- Добавил CLI для инференса, benchmark с прогревом и оценку качества на 16 383 предсказаниях WikiText-2

## Точное определение цифр

Производительность измерена на Apple M2 при batch=1 и длинах 128/128 токенов после 3 прогревов, по медиане 10 запусков

Сохранение качества — отношение next-token top-1 accuracy INT8 к FP16 на первых 16 384 токенах WikiText-2: 99,81%, 95% paired bootstrap CI 99,57–100,04%

Для INT4 сохранение этой же метрики составило 94,72%, а perplexity выросла на 18%
