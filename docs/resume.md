# Описание проекта для резюме

**LLM Quantization & Efficient Inference**

Разработал pipeline посттренировочного квантования Qwen2.5-0.5B в INT8/INT4
на Apple Silicon с использованием MLX. Для INT4 ускорил декодирование в 1,65×
и снизил пиковую выделенную память MLX на 62% относительно FP16. Реализовал
CLI для инференса и воспроизводимое сравнение производительности и perplexity
на WikiText-2.

Дополнительно: для INT8 получил ускорение 1,43× при росте perplexity на 0,09%.

Условия: Apple M2, batch=1, 128/128 токенов, 3 прогрева, 10 замеров.
Perplexity — на первых 16 384 токенах тестовой части WikiText-2.
