# Эксперимент с Qwen2.5-0.5B

Используем базовую модель `Qwen/Qwen2.5-0.5B`, не Instruct.
Это продолжение текста, а не ассистент с шаблоном чата.
Эксперимент Qwen завершён: INT4 дал 1,65× по decode и 62,1% экономии памяти
MLX, с ростом perplexity на 18% и сохранением 94,72% next-token accuracy

INT8 сохранил 99,81% next-token accuracy при ускорении 1,43×

Таблицы и условия приведены в README

Команды выполняются из корня проекта в обычном терминале VS Code.

## 1. Подготовить и проверить три точности

```sh
.venv/bin/python scripts/run_smoke_matrix.py --model qwen2.5-0.5b
```

Первый запуск скачает примерно 1 ГБ исходных весов. Кэш исходника и локальные
FP16/INT8/INT4-копии вместе займут несколько ГБ диска. Не запускайте этапы
параллельно: runner сам использует отдельный процесс для каждой операции.
Для обеих квантованных версий используется одна и та же локальная FP16-модель.
Её исходная ревизия сохраняется в source_revision.json.

## 2. Измерить производительность

```sh
.venv/bin/python scripts/benchmark_mlx.py --model qwen2.5-0.5b
```

Протокол прежний: 128 входных и 128 выходных токенов, batch=1,
3 прогрева, 10 замеров. Сравниваем форматы внутри Qwen, а не приписываем ей
ускорение, которое ранее получили на SmolLM2.

## 3. Оценить perplexity

```sh
.venv/bin/python scripts/evaluate_ppl.py --model qwen2.5-0.5b
```

Каждая модель использует собственный токенизатор. Поэтому абсолютная perplexity
Qwen и SmolLM2 не сопоставима напрямую. Даже первые 16 384 токена покрывают
разное количество исходного текста. Внутри одного эксперимента Qwen набор
токенов строго одинаков для всех трёх точностей.

## 4. Попробовать инференс

```sh
.venv/bin/python scripts/infer.py --model qwen2.5-0.5b --format int4 --prompt "Квантование нейросетей позволяет" --max-tokens 128
```

Поддерживаются `--temperature` и `--seed`. По умолчанию используется greedy
(temperature=0). Для сравнения отдельных продолжений переключайте --format,
но не оценивайте сохранение качества по одному примеру текста.

Без --model старые команды по-прежнему используют SmolLM2. Файлы моделей и
новые каталоги результатов Qwen содержат её имя; старые результаты сохраняются.
