# Первый запуск

Создайте виртуальное окружение и установите зависимости из
requirements-mlx.lock.txt. Команды выполняются из корня проекта.

```sh
.venv/bin/python scripts/run_smoke_matrix.py --model qwen2.5-0.5b
```

Сначала скрипт скачает исходные веса, сохранит их ревизию и приведёт к FP16.
Затем создаст INT8 и INT4 из этой локальной копии. Конвертация и генерация
выполняются последовательно, в отдельных процессах.

При повторном запуске готовые модели переиспользуются. Прерванная конвертация
не считается готовым результатом: неполные файлы сохраняются отдельно.
Если нужно подготовить FP16 конкретной ревизии на новой машине:

```sh
.venv/bin/python scripts/smoke_mlx.py --model qwen2.5-0.5b --revision 060db6499f32faf8b98477b0a26969ef7d8b9987
```

Проверочный прогон генерирует до 64 токенов и сохраняет JSON в results/.
Его задача — обнаружить проблемы загрузки и исполнения. Для измерений с
прогревом используйте benchmark_mlx.py.

Если MLX сообщает `No Metal device available`, запустите команду в обычном
терминале VS Code или macOS. В изолированной сессии доступ к GPU может отсутствовать.
