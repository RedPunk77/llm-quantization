# Результаты

JSON-файлы содержат исходные измерения, настройки и версии окружения.
Каталоги `benchmark-*` — замеры с прогревом, `perplexity-*` — оценка NLL/PPL.
Файлы `*-smoke-*` проверяют загрузку и генерацию; их скорость не используется
для итогового сравнения.

Основные результаты Qwen приведены в корневом README. Ранние каталоги без
имени модели относятся к SmolLM2; источник указан в каждом результате.
Новые каталоги Qwen содержат `qwen2.5-0.5b` в имени.

`corpus.json` содержит токены фрагмента WikiText-2. Источник и ревизия записаны
внутри файла. Корпус распространяется по условиям
[WikiText](https://huggingface.co/datasets/Salesforce/wikitext) (CC BY-SA 3.0 / GFDL).
